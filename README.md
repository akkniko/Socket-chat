# Мини-чат на Java-сокетах

## Инструкция по запуску

Нужен JDK 17+ 

**1. Скомпилировать:**

```bash
javac -d out $(find src -name "*.java")
```

**2. Запустить сервер** (в одном терминале; порт по умолчанию 12345):

```bash
java -cp out chat.server.ChatServer
# или на другом порту:
java -cp out chat.server.ChatServer 9000
```

**3. Запустить клиента** (в отдельном терминале):

```bash
java -cp out chat.client.ChatClient
# или к серверу на другой машине/порту:
java -cp out chat.client.ChatClient 192.168.1.10 9000
```

Каждый клиент при подключении спрашивает ник, далее - обычный чат

## Команды в чате

| Команда              | Функция                                      |
|----------------------|----------------------------------------------|
| `/list`              | Показать, кто сейчас в сети                  |
| `/w ник текст`       | Личное сообщение конкретному пользователю    |
| `/quit`              | Выйти из чата                                |

Любая другая строка - обычное сообщение, которое видят все

## Архитектура

```
ChatServer (main поток)
 │  ServerSocket.accept() в цикле
 │
 |---> ExecutorService (пул потоков)
 │      каждое подключение - отдельный ClientHandler в пуле,
 │      а не вручную созданный new Thread()
 │
 |---> ConcurrentHashMap<nickname, ClientHandler>
        общий реестр клиентов; из него же строится broadcast()
```

Клиент - 2 потока: главный поток читает консоль и пишет в сокет,
отдельный поток-слушатель читает сокет и печатает в консоль
